# 训练数据构建

这些模块把已验证的蒸馏轨迹转换为标准训练记录。输入路径、交付根目录和输出路径由参数指定，
每次输出到新目录，生成的 manifest 与审计记录描述本次来源及数量。

| 模块 | 输入 | 作用 |
| --- | --- | --- |
| `training` | 标准轨迹、配对初始请求、通过样本索引及交付根目录 | 清理模型可见内容，补齐公开工具，生成训练记录与审计信息 |
| `paths` | 上一步输出目录 | 转换运行路径，检查主机路径暴露并保存修正记录 |
| `merge` | 清理结果、来源数据、补充轨迹目录 | 合并完整轨迹和已有上下文压缩续接记录 |
| `windows` | 数据集、原始请求与完整轨迹 | 按真实压缩边界重建模型可见窗口，检查调用和结果配对 |
| `append` | 既有训练数据、扫描根目录、排除项与交付根目录 | 按 canonical PASS 索引和实际通过 verdict 增补样本 |

运行 `python -m distill.dataset.<模块> --help` 查看完整参数。输入 JSONL 的顺序和轨迹 ID 必须配对一致。
原始请求、Verifier 结果与交付包需要保留，供来源审计和复验。公开训练记录与审计元数据分别保存。

这些构建器输出工具调用 SFT 所需的消息、工具定义与真实结果；训练端仍负责其模型模板、损失掩码和采样配置。
任务生成、工具验收和样本筛选各自保存判定依据。
