全量索引是规定范围内的源码参考 API，不是运行时 `dir()` 的全部导出。导入别名、继承、dataclass/Pydantic 自动构造和外部依赖不会重复展开。包内 samples/CLI 等源码保留在全量中，精选排除；例如 gdsfactory 的数字样例模块不作为精选可调用模块。

## 原生接口与筛选边界

KLayout 从发布版自带的 `*core.pyi` 和 Python 包源码提取，并依据 `__init__.py` 映射为 `klayout.db/lay/lib/rdb/tl/pex`。同名重载计一次，以参数最多的真实签名作为代表（并列取第一个）；全部重载说明保存在 `others.python_source_extraction.native_overloads`。注解数据属性不假装成方法。精选只保留 `klayout.db` 无界面几何核心，未编译核对 stub 与实际绑定的一致性。

Gmsh 从官方 `api/gmsh.py` 提取。`model.mesh`、`model.occ` 等是静态 API 命名空间，不是需要实例化的业务类，因此递归展开为带真实命名空间的函数；不重复计 snake_case 别名。`Types` 和 `Return` 段提供类型及命名返回值，参数含义没有独立说明时继续留空。

meshio 精选 21 个调用：统一 `read/write/write_points_cells`、Mesh/CellBlock 和 XDMF 时间序列足以覆盖核心流程。没有添加数十套格式内部读写函数凑数。时间序列必须使用上下文管理器，生命周期魔术方法按当前统计政策未收录，后续封装应自动管理文件关闭。

ShakeNBreak 全量 55 个调用，去除 11 个 Click 命令行入口、`bold_print`、`plot_colorbar` 后精选 42。已在 profile、精选与报告中写明目标例外，其余新包均在 50–100 内。

`pymatgen` 最新版本依赖 `pymatgen-core>=2026.4.16`，已有 core 版本满足声明的下限；这不是依赖组合运行通过的证据。核心结构和相图不在本包重复索引，新增精选偏向能量修正、配位、衍射/光学、表面及迁移势垒。源码定义模块可能与用户常用重导出入口不同，按来源模块记录。

## 后续组合环境的接口边界（设计示例，未执行）

版图链：gdsfactory 生成组件 → KLayout 查询区域/布尔运算 → 根据工艺层厚度与 z 坐标构造 Gmsh 几何 → 物理分组与网格生成 → meshio 检查/转换节点、单元和标签 → DEVSIM 映射 region/contact/interface → 配置材料模型和方程 → 求解及数值检查。
gdsfactory 的仿真集成依赖可选 `gplugins`，本次没有额外采集该包。现有函数集不意味着上述链已经自动连通；需定义坐标单位、层到材料映射、单元类型、MSH 版本及物理组标签。DEVSIM 原生文档也支持坐标/单元/physical_names 数组导入，但数组编码不同于 meshio 原始结构，不能直接透传。

缺陷链：pymatgen-core 构造晶体 → defects/doped 生成缺陷与超胞 → ShakeNBreak 产生畸变候选 → 使用固定的已完成弛豫样例 → doped/defects 解析和电荷修正 → doped 或 py-sc-fermi 求解浓度/费米能级。需统一形成能参考、化学势、DOS 归一化、晶胞体积、浓度单位及简并度，明确冻结浓度约束。DFT/VASP 执行、赝势和许可不由此次采集解决。

建议后续验证：GDS 读写前后的面积/层次；网格单元质量、物理标签和区域连通性；固定种子畸变及结构比较；已知形成能的跃迁交点；电中性残差和固定浓度约束。以上均是计划，尚未执行。
