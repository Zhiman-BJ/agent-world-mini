# Codex + 静态工具 verifier：首轮结果

实现入口：[codex_tool_verifier/README.md](codex_tool_verifier/README.md)。模型 `gpt-6-astra`，推理 `medium`。先固定 rubric，逐工具生成自测，再由一个主 Codex 调用工具、提交逐项分数；宿主聚合、留档、监督异常整任务回退。

四例均完成生成和主流程，未回退；参考样本满分 **1/4**。按已有参考运行暂视为正确的口径，另外三例尚未通过参考验收，不算端到端设计成功。

## 需要看清的结果

- **S21**：工具计算矩阵统计、最近邻尺度、12 组聚类试算及保存结果；2 次调用均成功，合计 2.55 秒，结果被 R1–R5 引用。扣分是最终答复只写了一幅预览图尺寸。主 Codex 期间发生流式解析异常和断流重连，最终在 900 秒预算内完成，没有回退。
- **S24**：公式和专业解释交给主 Codex；生成器评估静态工具无明显收益，生成 0 个工具，满分。
- **S81**：0 个工具。低分来自生成标准中的细节要求，例如额外的采集条件、时序机制解释及升级证据清单。R5 的每个小项必须同时满足全部细节才能得分，最终为 0/5；需核对是否把原材料中的信息过多转成了必须交付的要求。不能据此直接认定参考答案错误。
- **S56**：0 个工具。三项各扣 1/5，涉及结论附近的引用定位、单位换算/分母说明、精确比例的边界表述。应核对这些要求的尺度是否符合原任务。
- **S91**：未进入生成。参考终态中有其他用户持有且不可读的文件，证据复制报 PermissionError；保留原始错误，补跑 S56。不把这次准备失败计作生成失败。

## 验证与限制

- 新旧机制测试 **77 项通过**；Python 编译及三个 CLI 帮助入口正常。审查发现的最终回复写入权限、满分浮点计算、模型启动统计问题均已修复。真实客户端/沙箱、工具调用、异常停止及整任务回退均有机制测试。
- 三例没有生成静态工具，只有 S21 测到了真实静态工具调用。尚未与相同任务的旧 verifier 做同条件成本对比，不能宣称整体更便宜或更快。
- 本批没有触发真实回退，回退机制仅在测试中验证。未生成任务负例，不评价错误识别准确率。
